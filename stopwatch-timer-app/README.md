# Chrono

A small React app providing a stopwatch and a configurable countdown timer with 10ms precision.

Core stack: React, TypeScript, Vite, Tailwind CSS

Project structure: [src/components](src/components), [src/hooks](src/hooks), [src/utils](src/utils)

**Setup**

Install dependencies: `npm install`
Start development server: `npm run dev`

**Available scripts**
- `dev`: start Vite dev server
- `build`: compile TypeScript and build with Vite
- `preview`: preview production build

Notes: UI styles are in [src/index.css](src/index.css) and Tailwind is used.
